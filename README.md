# EasyPDFConverter

Конвертер PDF в картинки PNG или JPEG в максимальном качестве. Для Windows, без установки.

Положите PDF в папку, запустите `EasyPDFConverter.bat`, ответьте на два вопроса. Каждая страница станет отдельной картинкой.

## Быстрый старт

1. Скачайте репозиторий: кнопка **Code → Download ZIP**, затем распакуйте. Или:
   ```
   git clone https://github.com/baslie/EasyPDFConverter.git
   ```
2. Положите PDF-файлы в папку рядом с `EasyPDFConverter.bat`. Можно сразу несколько.
3. Дважды щёлкните по `EasyPDFConverter.bat`. Откроется окно консоли.
4. Ответьте на два вопроса:
   - формат: **PNG** (без потерь) или **JPEG** (качество 100);
   - разрешение: 150, 300 или 600 DPI, либо своё число.
5. Готовые картинки появятся в папке `output`, по подпапке на каждый PDF. Папка откроется сама.

При первом запуске скрипт скачает портативную сборку Poppler (около 16 МБ) в папку `tools`. Дальше интернет не нужен.

## Что получится

```
EasyPDFConverter\
├── договор.pdf
├── презентация.pdf
└── output\
    ├── договор\
    │   ├── договор-1.png
    │   ├── договор-2.png
    │   └── договор-3.png
    └── презентация\
        ├── презентация-01.png
        ├── ...
        └── презентация-24.png
```

Номера страниц дополняются нулями до одинаковой длины, поэтому файлы сортируются правильно в любом проводнике.

## Качество

Скрипт не ужимает картинки.

| Формат | Что внутри |
|--------|-----------|
| PNG | 24-битный RGB без потерь. Самый точный вариант. |
| JPEG | Качество 100, оптимизированные таблицы Хаффмана. Файлы в 2–3 раза меньше PNG. |

Разрешение определяет размер картинки. Для страницы A4:

| DPI | Размер в пикселях | Для чего |
|-----|-------------------|----------|
| 150 | 1240 × 1754 | Экран, мессенджеры |
| 300 | 2480 × 3508 | Печать, документы. Рекомендуется |
| 600 | 4961 × 7016 | Мелкие чертежи, максимальная детализация |

Рендеринг идёт со сглаживанием шрифтов и векторной графики, границы страницы берутся по CropBox, как показывает любой PDF-просмотрщик.

## Дополнительные способы запуска

**Перетащить файлы.** Возьмите один или несколько PDF мышкой и бросьте на `EasyPDFConverter.bat`. Обработаются только они, а не вся папка.

**Из командной строки без вопросов.** Скрипт принимает параметры, поэтому его удобно вызывать из других скриптов:

```powershell
# Все PDF из папки скрипта в PNG при 600 DPI, папку output не открывать
powershell -ExecutionPolicy Bypass -File .\EasyPDFConverter.ps1 -Format png -Dpi 600 -NoOpen

# Один конкретный файл в JPEG, DPI спросит
powershell -ExecutionPolicy Bypass -File .\EasyPDFConverter.ps1 "D:\Сканы\договор.pdf" -Format jpeg

# Целая папка
powershell -ExecutionPolicy Bypass -File .\EasyPDFConverter.ps1 "D:\Сканы" -Format png -Dpi 300
```

| Параметр | Значение |
|----------|----------|
| `-Format` | `png` или `jpeg` |
| `-Dpi` | число от 36 до 2400 |
| `-NoOpen` | не открывать папку `output` в Проводнике |
| `-NoPause` | не ждать нажатия клавиши в конце |
| позиционные аргументы | пути к PDF-файлам или папкам |

## Как это работает

Рендеринг выполняет `pdftoppm` из проекта [Poppler](https://poppler.freedesktop.org/), одного из самых точных открытых движков PDF. Используется портативная сборка для Windows из репозитория [oschwartz10612/poppler-windows](https://github.com/oschwartz10612/poppler-windows).

При первом запуске скрипт:

1. запрашивает у GitHub последний релиз Poppler;
2. скачивает архив в `tools\` и распаковывает в `tools\poppler\`;
3. дальше использует локальную копию.

Если Poppler уже установлен в системе и есть в `PATH`, скрипт возьмёт его.

Если интернета нет, скачайте `Release-*.zip` со [страницы релизов](https://github.com/oschwartz10612/poppler-windows/releases) вручную и распакуйте в `tools\poppler\`. Скрипт найдёт `pdftoppm.exe` в любой подпапке.

## Требования

- Windows 10 или 11.
- Windows PowerShell 5.1. Он встроен в систему, устанавливать ничего не нужно.
- Интернет для первого запуска.

## Возможные вопросы

**Windows пишет «Система Windows защитила ваш компьютер».**
Это SmartScreen, он так реагирует на любой скачанный `.bat`. Нажмите «Подробнее», затем «Выполнить в любом случае». Скрипт открыт, его можно прочитать целиком в `EasyPDFConverter.ps1`.

**Окно мигнуло и закрылось.**
Запустите `EasyPDFConverter.bat` из командной строки, чтобы увидеть сообщение об ошибке. Чаще всего дело в заблокированном антивирусом `tools\poppler`.

**PDF с паролем.**
Не поддерживаются. Снимите пароль в любом PDF-редакторе и повторите.

**Нужно переконвертировать в другом формате.**
Просто запустите ещё раз. Файлы с тем же расширением в `output\<имя>\` перезапишутся, другие останутся.

**Можно ли переименовать папку.**
Да. Скрипт работает относительно своего расположения, имя папки не важно.

## Структура репозитория

| Файл | Назначение |
|------|-----------|
| `EasyPDFConverter.bat` | Лаунчер для двойного клика. Открывает консоль и запускает скрипт. |
| `EasyPDFConverter.ps1` | Основной скрипт: поиск PDF, вопросы, загрузка Poppler, конвертация. |
| `.gitignore` | Исключает `tools\`, `output\` и PDF из репозитория. |
